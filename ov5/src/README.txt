【工程说明】
本工程基于 Zynq-7020 (BX71-V4) 实现软硬协同视频处理。

1. 硬件部分：基于双 VDMA、VTC、Dynclk 等 IP 构建了视频采集与显示链路。已针对 BX71 板卡完成 XDC 引脚重映射与 DDR3L 适配。
2. 软件部分：因最新版 Vitis 2026.1 底层 CMake 构建系统存在严重 Bug，导致多文件工程无法正确链接。故采用“单文件直写”与“硬编码基地址”的方式，绕过了底层 BSP 的宏定义缺失问题，成功完成了 EMIO I2C 配置与 VDMA 数据流启动。
3. 当前成果：ARM 端已成功通过 VDMA 从 DDR 中读取到视频像素数据（0x3f7fef1d），系统底层总线与数据流转已彻底打通。
